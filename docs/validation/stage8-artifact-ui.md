# 阶段八：独立服务产物界面中间验收

使用独立 PostgreSQL 测试库、Docker API 和真实 Run Worker，浏览器通过真实登录、批准、持久 Run 和工作负载容器生成文件。回答模型为脚本替身，无收费模型调用；Docker Desktop 使用显式开发例外，不能替代生产 rootless 验收。业务库和业务配置未更改。

- 授权弹窗显示目录修订、工具版本、无网络与临时工作区，并展示时间、内存、CPU、进程数、输出、工作区和导出文件限额。限额缺失、非数值或不一致时拒绝形成批准草稿；旧同名 HTTP 工具保持原语义。
- 成功运行生成 4 个真实文件：UTF-8 文本、120×80 PNG、长文本及 SVG。列表显示大小、工具版本和摘要。文本按字面预览，长文本提示截断，图片正常显示，SVG 仅提供附件下载。
- 浏览器实际下载 answer.txt 后，磁盘文件 SHA-256 与数据库原始摘要一致。Escape 关闭预览并返回原按钮焦点。刷新恢复一个文件区，数据库仍只有该成功运行的 4 份产物。
- 切换团队清空个人文件区；退出后登录普通账号并打开原管理员会话，显示资源不存在，文件区数量为零。延迟响应及刷新令牌切换账号的隔离另有前端回归覆盖。
- 浏览器发起第二次运行，观察真实运行中的工作负载容器后点击停止；页面显示已取消，数据库状态 cancelled，该运行没有产物。核查工作负载容器无残留。
- 独立 API 无 Docker socket，只有可信 Run Worker 挂载本地 socket；工作负载无宿主挂载。前端构建通过，42 项 Node 测试通过。后端仍引用前次全量 755 passed、51 skipped、38 subtests passed，本轮前端改动未冒充新后端全量。
