# 能力中心与 Skill / Tool 管理

能力中心展示当前账号可使用的 Skill 和 Tool、版本、权限要求及不可用原因。管理员从“平台管理 → Skill / Tool 管理”创建、编辑、启停和删除定义，历史版本继续保留。工具仍被任何 Skill 引用时不能删除；已启用 Skill 不能依赖停用的自定义工具。删除后的标识不能重新使用。

聊天中通过“选择能力”、Ctrl/Cmd+K 或 `/skill-name 问题` 激活 Skill；清除选择后恢复普通调度。Skill 提供指令和工具白名单，不能扩大资料、SQL、网络、记忆或执行预算权限。切换账号或空间会清空选择。上下文估算包含 Skill 指令；指令本身超预算时需调整配置。

## 启用和升级

1. 在原配置下完成或明确取消活动 Run 和评测任务。旧任务没有能力快照时不能自动升级或重写检查点。
2. 停止写入并备份数据库、服务端配置、上传和解析目录，执行 `python -m app.migrate`。迁移 `0009_capability_control` 创建当前目录与不可变版本表，并初始化三个内置 Skill。
3. API、Run Worker 和评测 Worker 使用相同的 `CAPABILITY_CENTER_ENABLED=true`，保留 `CHAT_RUNS_ENABLED=true` 和独立 Run Worker。按需设置 `CAPABILITY_SECRET_NAMES=["PUBLIC_API_TOKEN"]`，并在各执行实例的服务端环境提供对应值；不要把值填写到能力表单。
4. 按[部署预检](deployment-preflight.md)先检查存储与历史快照，再启动匹配的 Worker 并运行完整预检，最后开放 API。完整 Compose 配置包含此开关；基础配置继续默认关闭。

目录更新通过数据库共享，不要求重启 Worker。Run 入队冻结目录、Skill、允许工具和 SQL 策略；更新指令、端点或普通运行参数不改写旧任务。执行和发布前复核当前停用、角色、Secret 名称及 SQL 范围，撤权后拒绝继续。Secret 值由执行实例环境解析，不进入版本历史。

## 内置工具配置

SQL 使用服务端 `SQL_DATABASE_URL` 指定的独立 PostgreSQL 只读连接，页面只能管理表白名单、来源名称、超时和最多 100 行的返回限制。启用前实际核验数据库角色和表；角色拥有写入或 DDL 权限、连接指向平台库、表无效时拒绝保存。查询仍经过既有单条 SELECT、关系/函数白名单和只读事务校验。平台及系统 schema 禁止查询。

更换数据库身份或收缩表白名单会使旧运行失效；仅轮换密码不改变连接身份。运行使用自己的冻结策略和客户端，并在结束时关闭。配置保存成功只证明核验时有效，后续数据库权限改变仍会在实际查询中被只读校验拒绝。

网页开关控制内置搜索和页面读取。搜索还需原有 `WEB_SEARCH_ENABLED` 与服务端 Tavily 配置；没有搜索服务时仍可读取明确提供的公共网页。自定义 HTTP Tool 单独管理，不通过网页开关改变它的授权。

## 自定义 HTTP Tool

支持 GET/POST、公共 HTTPS 地址、对象 JSON Schema 2020-12 参数、固定头、Secret 名称引用、超时和响应大小上限。注册和调用均校验配置；连接固定到经过校验的公共 DNS 目标，拒绝私网地址和重定向，响应必须为 JSON 对象。不执行上传代码。

参数 Agent 只接收本轮冻结的公开查询，不接收私有检索、SQL、会话历史或摘要。工具返回内容进入证据与预算，引用显示工具标识、版本和实际响应片段。HITL 补充输入不会自动外发；需要更新公开输入时，使用独立的“允许发送给公共工具的完整查询”字段。

有副作用的工具应关闭幂等标记；执行结果无法确认时不会自动重发。审批链路属于后续阶段，目前标记“需要审批”的工具明确不可执行，不能以注册成功当作审批通过。

## 管理接口

所有路径位于 `/api/v2/capability-center`。当前目录和 Skill 说明要求登录；`control-plane`、`versions`、所有写入要求平台管理员。写入携带 `expected_revision`，冲突返回 409，需刷新核对后重试。

| 路径 | 方法 | 用途 |
| --- | --- | --- |
| 根路径 | GET | 当前角色的目录和可用性 |
| `/skills/{name}` | GET | 获准 Skill 的指令和版本 |
| `/control-plane`、`/versions` | GET | 管理配置、分页版本历史 |
| `/skills`、`/tools` | POST | 创建定义 |
| `/skills/{name}`、`/tools/{name}` | PUT / DELETE | 更新或删除 |
| `/runtime/sql`、`/runtime/web` | PUT | 版本化内置工具配置 |

实际阶段状态及验收边界见[补齐进度](replication-repair-progress.md)，不以页面或目录存在证明整阶段部署、审批或问答质量已经完成。
